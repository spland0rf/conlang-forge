# Ekki Potak: a beginner's course

*Language 101 for Ekki Potak. Seed 2014871053. Every word and ending in this book is read straight from the language, so the examples always agree with the rules.*

## How to use this book

Each lesson gives the **rules** first, then **short examples** with a word-by-word translation. In the examples the first line is the sentence in the language, the second line translates each word or ending in turn (small capitals such as PST or PL are grammar labels, explained at the end of the book), and the third line is natural English. Work through the lessons in order, then try the exercises and check yourself against the answer key.

## The language at a glance

|  |  |
|---|---|
| Type | isolating: words do not change shape; small separate words carry the grammar |
| Basic word order | SVO: subject, verb, object |
| Grammar is added with | no affixes at all (small separate words) |
| Adjectives | come after the noun |
| Owners | come after the thing owned |
| Little words like 'in' | come after the noun (postpositions) |
| Number | not marked on nouns |
| Cases | none (word order and little words do the work) |
| Genders | masculine, feminine |
| Articles | none ('the' and 'a' are not said) |
| Tenses | past, non-past |
| Aspects | perfective, imperfective |
| Moods | indicative, imperative |
| Verbs agree with | nothing |
| Alignment | nominative-accusative |
| Counting base | 8 |

## Lesson 3: Pronouns and 'to be'

| English | Subject | Object (me, him ...) | Owner (my, his ...) |
|---|---|---|---|
| I | luk | luk ek | loma |
| you | ka | ka ek | ka to |
| he | sdi | sdi ek | sdi to |
| she | nasde | nasde ek | nasde to |
| it | pok | pok ek | pok to |
| we | sda | sda ek | sda to |
| they | lem | lem ek | lem to |

> **Rule.** The object form is the subject form plus the object ending, and the owner form is the subject form plus the possessive ending. Learn the seven subject pronouns and you can build all of the rest.

**This and that**

| English | Ekki Potak |
|---|---|
| this | duksa |
| that | duk |
| these | duksa mo |
| those | duk mo |

> *The plural forms are the singular forms plus the plural ending.*

> **Rule.** Subject pronouns are **always said**, because the verb does not show who is acting.

**To be**

> **Rule.** In the present tense there is **no word for 'is/am/are'**: you just put the two parts side by side ("I teacher"). In other tenses the verb ‘be’ is used.

```
luk  nipe
I    wizard
'I am a wizard.'
```

```
ka   nona
you  happy
'You are happy.'
```

```
neto  ketpe
dog   big
'The dog is big.'
```

```
sda  mepek
we   friend
'We are friends.'
```

```
nasde  tata
she    queen
'She is a queen.'
```

> **Rule.** This language counts in **8s**. The numbers 1 to 10 have their own words. Above that, say the large part and then the rest, biggest part first. For example 23 is said 'ma etna dut' (two eight seven).

**Counting things**

> **Rule.** When you count, a **class word** follows the number. It depends on the noun's class (see Lesson 5).

- one dog: **ak mom neto**
- three horses: **am mom leto**
- five kings: **na meko tata tom**

> **Rule.** Nouns **do not change** for number: the same word means 'dog' and 'dogs'. Context or a number word tells you which.

**Gender**

> **Rule.** Every noun belongs to one of these classes: masculine, feminine. Nouns themselves do not change; the class shows up only in the **class word** said after a number or 'this/that'.

| Gender / class | Class word | Examples |
|---|---|---|
| M | the word **meko** placed before the noun | man, boy, father, brother, king, knight, enemy, cat, fox |
| F | the word **mom** placed before the noun | woman, girl, child, mother, sister, friend, queen, wizard, priest |

**'The' and 'a'**

> **Rule.** There are **no articles**: 'the dragon' and 'a dragon' are both just 'dragon'.

> **Rule.** This language has **no cases**: nouns never change for their job in a sentence. Word order and little words (postpositions) show who does what to whom.

## Lesson 6: Verbs and how to conjugate them

| English | Ekki Potak | takes an object? |
|---|---|---|
| be | no | no |
| have | on | yes |
| go | emta | no |
| come | onik | no |
| see | lisde | yes |
| hear | doke | yes |
| eat | lekokkepin | yes |
| drink | lisda | yes |
| sleep | letasdapo | no |
| love | nenat | yes |
| fight | kane | no |
| die | tem mepo et | no |
| give | kekan | yes |
| say | ette | yes |
| take | dosdo | yes |
| make | kepek | yes |
| know | sokle | yes |
| want | puklen | yes |
| need | kelepe | yes |
| like | la | yes |
| live | mepo et | no |
| work | tene | no |
| help | akneme | yes |
| ask | mineket | yes |
| tell | monleka | yes |
| think | kamen | no |
| speak | ematek | no |
| read | pitenan | yes |
| write | paten | yes |
| walk | paku | no |
| run | takun | no |
| buy | enmum | yes |
| find | tikke | yes |

> **Rule.** Look verbs up in the dictionary in this form, the **stem**. Every ending below attaches to the stem (here, as small separate words in front of it).

> **Rule.** Verbs **do not change** for person or number: 'sees' is the same word whoever sees.

**Time: tense**

| Tense | Label | Marker | English | 'go' |
|---|---|---|---|---|
| past | PST | the word **kome** placed before the verb | I went | luk kome emta |
| non-past | NPST | (no ending) | I go / I will go | luk emta |

> *Non-past covers both the present and the future.*

**How the action unfolds: aspect**

> **Rule.** Aspect shows whether an action is finished, ongoing or habitual. **perfective** is the plain form (no ending); the others add one.

| Aspect | Label | Marker | Meaning | 'he eats bread' |
|---|---|---|---|---|
| perfective | PFV | (no ending) | he ate (the whole thing, done) | sdi lekokkepin koka |
| imperfective | IPFV | the word **keke** placed before the verb | he was eating / used to eat | sdi keke lekokkepin koka |

**Commands and wishes: mood**

> **Rule.** The plain form (**indicative**) states facts. The **imperative** adds the word **meme** placed before the verb.

| Mood | Label | English | 'eat bread' |
|---|---|---|---|
| imperative | IMP | Eat! | meme lekokkepin koka |

**How do you know? Evidentiality**

> **Rule.** A verb ending also shows how the speaker knows. Unmarked means seen firsthand; **the word **tote** placed before the verb** means 'they say'; **the word **kote** placed before the verb** means 'it seems'.

```
sdi  tote  lekokkepin  koka
he   REP   eat         bread
'(They say) he eats bread.'
```

```
sdi  kote  lekokkepin  koka
he   INFR  eat         bread
'(It seems) he eats bread.'
```

**Order of the endings**

> **Rule.** A verb is built from the stem plus these separate small words, in this order: **EVIDENTIAL + MOOD + TENSE + ASPECT + STEM**. Leave out any you do not need. The order never changes. 

**Saying 'not'**

> **Rule.** To negate, the word **en** goes **right before the verb**.

```
luk  en   emta
I    not  go
'I do not go.'
```

```
menan   en   letasdapo
dragon  not  sleep
'The dragon does not sleep.'
```

**Building new words**

> **Rule.** Most new words are made from old ones with regular endings. The same ending works on any root.

| Meaning | Recipe | English | Ekki Potak |
|---|---|---|---|
| 'one who does X / is concerned with X' | teach +AGENT | teacher | tek kame ko |
| abstract noun | free +ABSTRACT | freedom | mikeni kek |
| adjective | danger +ADJ | dangerous | ukekpokuk ke |
| adverb | quick +ADV | quickly | laknekkitli te |
| 'not X' | happy +NEG | unhappy | me nona |
| 'to X again' | build +AGAIN | rebuild | mem polek |
| 'female X' | king +FEMALE | queen | tata tom om |
| 'lesser or weaker X' | house +DIMIN | little house | dika kem |
| 'a place for X' | work +PLACE | workplace | tene tet |

| small | tem ketpe |
| old | tem kopet |
| new | kopet |
| young | motke |
| long | nepupak |

| dangerous | ukekpokuk ke |
| brave | eke |
| clean | loke |
| good | kokeko |
| bad | ase |

> **Rule.** An adjective comes **after** the noun it describes.

> **Rule.** Adjectives are single words that never change.

- the big man: **saten tom ketpe**
- the big woman: **saten ketpe**

```
nipe    tem kopet  lisde  menan   ketpe

```

```

'The horse is fast.'
```

**More and most**

> **Rule.** To compare, add the comparative ending (**the word e before it**: 'bigger') or the superlative ending (**the word mek before it**: 'biggest') to the adjective. To make an adverb ('quickly') add **the word te after it**.

| English | Recipe | Ekki Potak |
|---|---|---|
| bigger | big +COMPAR | e ketpe |
| biggest | big +SUPERL | mek ketpe |
| quickly | quick +ADV | laknekkitli te |

## Lesson 8: Building sentences

> **Rule.** The basic word order is **SVO** (the verb comes in the middle).

**1. Subject and verb**

```
nipe    letasdapo
wizard  sleep
'The wizard sleeps.'
```

**2. Adding an object**

```
nipe    lisde  menan
wizard  see    dragon
'The wizard sees the dragon.'
```

**3. Describing with adjectives**

```
nipe    tem kopet  lisde  menan   ketpe
wizard  old        see    dragon  big
'The old wizard sees the big dragon.'
```

**4. Saying whose it is**

> **Rule.** The owner comes **after** the thing owned, marked with the possessive ending.

```
neto  loma  lekokkepin  koka
dog   my    eat         bread
'My dog eats the bread.'
```

```
leto   tata tom  to    kemnipi
horse  king      POSS  fast
'The king's horse is fast.'
```

**5. Where, when and with what**

> **Rule.** Places and directions use **postpositions**: a little word like 'in' or 'to' placed after the noun.

```
nipe    paku  sadu    pem
wizard  walk  forest  in
'The wizard walks in the forest.'
```

```
nipe    kekan  pite  tata tom  tat
wizard  give   book  king      to
'The wizard gives the book to the king.'
```

```
luk  kane   telenan  net
I    fight  sword    with
'I fight with a sword.'
```

**6. Past and future**

```
nipe    kome  lisde  menan
wizard  PST   see    dragon
'The wizard saw the dragon.'
```

```
nipe    lisde  menan
wizard  see    dragon
'The wizard will see the dragon.'
```

> *There is no separate future here: the non-past form means both 'does' and 'will do'.*

**7. Joining sentences**

> **Rule.** Join two sentences with **dak** ('and') or **sek** ('but') between them.

```
nipe    letasdapo  dak  menan   letasdapo
wizard  sleep      and  dragon  sleep
'The wizard sleeps and the dragon sleeps.'
```

**8. Having**

```
tata tom  on    moka
king      have  castle
'The king has a castle.'
```

## Lesson 9: Questions, answers and 'not'

**Yes/no questions**

> **Rule.** A question has **the same words as a statement**; only the voice rises at the end.

```
nipe    lisde  menan
wizard  see    dragon
'The wizard sees the dragon.'
```

```
nipe    lisde  menan
wizard  see    dragon
'Does the wizard see the dragon? (said with a rising voice)'
```

```
menan   ketpe
dragon  big
'Is the dragon big?'
```

**Answers**

- Yes: **mon** / No: **nik**

> **Rule.** To answer, say yes or no, or repeat the sentence with the verb.

**Question words**

| English | Ekki Potak |
|---|---|
| who | kin |
| what | lum |
| which | lin |
| where | ponda |
| when | pon |
| why | sdo |
| how | sit |

> **Rule.** A question word goes at the **start** of the sentence.

```
kin  lisde  menan
who  see    dragon
'Who sees the dragon?'
```

```
lum   ek   nipe    lisde
what  ACC  wizard  see
'What does the wizard see?'
```

```
ponda  nipe    letasdapo
where  wizard  sleep
'Where does the wizard sleep?'
```

```
sdo  menan   letasdapo
why  dragon  sleep
'Why does the dragon sleep?'
```

```
sit  nipe    paku
how  wizard  walk
'How does the wizard walk?'
```

**Saying 'not'** (review)

```
nipe    en   lisde  menan
wizard  not  see    dragon
'The wizard does not see the dragon.'
```

```
luk  en   sokle
I    not  know
'I do not know.'
```

```
kin  en   letasdapo
who  not  sleep
'Who does not sleep?'
```
